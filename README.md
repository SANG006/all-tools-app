# All Tools

เว็บใช้งาน: https://sang006.github.io/all-tools-app/

ศูนย์รวมเครื่องมือ 4 ตัวในแอปเดียว:

- ค้นหาอะไหล่สโตร์ (5,861 รายการ)
- คำนวณมู่เล่ย์
- คำนวณ Roller
- จำลองลำดับมอเตอร์ V3

## ใช้งาน

เปิดเว็บที่ deploy แล้ว หรือเปิด index.html ด้วย Chrome / Edge
สลับเมนูได้โดยค่าที่กรอกไม่ถูกล้าง เครื่องมือที่เริ่มจำลองไว้ยังทำงานจนกว่าจะหยุดหรือปิดหน้า
โค้ดและข้อมูลต้นฉบับฝังอยู่ครบใน index.html โดยแต่ละเครื่องมือแยกหน้าจอภายในเพื่อป้องกันโค้ดและสไตล์ชนกัน

## Deploy ด้วย GitHub Pages

ที่ Settings → Pages เลือก Source เป็น Deploy from a branch แล้วเลือก main และ / (root)
ทุกครั้งที่ push เข้า main ระบบ GitHub Pages จะ deploy เว็บอัตโนมัติ
เว็บรองรับการอยู่ใต้ชื่อ repository โดยไม่ต้องเปลี่ยนเส้นทางไฟล์

## เงื่อนไขเดิม

- บางเครื่องมือต้องใช้อินเทอร์เน็ตโหลด Tailwind, ฟอนต์ และไอคอน
- งานที่ยังไม่บันทึกจะหายเมื่อรีโหลดหรือปิดหน้า
- รายการโปรดและธีมเก็บในเบราว์เซอร์ของแต่ละคน ไม่ได้แชร์ข้ามเครื่อง และไม่ย้ายจากไฟล์เดิมมาเว็บใหม่อัตโนมัติ
- ฐานข้อมูลอะไหล่ฝังอยู่ในหน้าเว็บ ผู้ที่เข้าถึงเว็บหรือ repository จะอ่านข้อมูลนี้ได้

## การตรวจสอบ

ตรวจความตรงกันของข้อมูลที่ฝังกับไฟล์ต้นฉบับทั้ง 4 ตัว และทดสอบการค้นหาอะไหล่ การคำนวณมู่เล่ย์ทั้งสองโหมด Roller ทั้งสามโหมด เริ่ม/หยุดมอเตอร์ ส่งออก CSV และเก็บค่าระหว่างสลับเครื่องมือ
